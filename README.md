# 🌦️ Weathix — Weather Application

A responsive weather application built with HTML, CSS, and JavaScript. This project is a learning and customization project based on the original work by [Moinak Ghosh](https://github.com/moinakgh99/Weathix-Weather-Application).

## ✨ Features

- Search for weather by city
- Display weather information retrieved through an API
- Show weather conditions and related details
- Responsive user interface
- Weather animations and styling

_Features listed above should be checked against the current implementation._

## 🛠️ Tech Stack

- **HTML5** — Page structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Application logic and dynamic content
- **Weather API** — Weather data retrieval

## 🚀 Getting Started

### 1. Clone this repository

```bash
git clone https://github.com/YOUR-USERNAME/weathix-weather-app.git
```

### 2. Open the project folder

```bash
cd weathix-weather-app
```

### 3. Run the application

Open `index.html` in your browser, or use the Live Server extension in VS Code.
